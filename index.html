INNOVATEX IOT · User Manual Welcome
Getting Started

Welcome

◆

The INNOVATEX IOT system keeps watch over your site. It measures the conditions around the installation — temperature, humidity, light, distance and motion — and shows them on a simple dashboard you can open from any phone, tablet or computer. From the same screen you can also switch the site's alarm and perimeter lighting on and off.

What You Can Monitor

  • Temperature
  • Humidity
  • Ambient light
  • Distance / proximity
  • Motion
  • Live camera view
  • Overall system status

What You Can Control

  • Audible alarm
  • Perimeter lighting

How You Use It

Once the system is installed and connected, it runs on its own. Your job as an operator is straightforward: make sure it is powered and connected, open the dashboard, and act on what you see there.

This Manual

If you are using the system for the first time, start with Quick Start on the next page. Everything else in this manual is reference material you can return to when you need it.

Preparation

Before You Start

◆

A quick check before switching anything on prevents most problems later. Make sure you have the following ready.

What You Need

  • The INNOVATEX IOT monitoring unit, installed in place.
  • All sensors connected.
  • The camera connected, if your system includes one.
  • A suitable power supply, connected and ready.
  • A Wi-Fi network at the site with internet access.
  • The Wi-Fi network name and password.
  • A phone, tablet, or computer for the dashboard.
  • Your dashboard username and password.

Before Switching On

  • Check that every cable and connector is firmly in place.
  • Check that the unit is not exposed to water, heat, or direct sunlight.
  • Check that the power supply matches the equipment.
Important

Do not connect or disconnect sensors while the unit is powered on. Switch the power off first, unless your installer has told you otherwise.

INNOVATEX IOT · User Manual Powering Up
Starting the System

Powering Up

◆

Follow this sequence whenever the system needs to be started — whether it is the first installation or a restart after maintenance.

  1. Check the connections.
    • Sensors connected.
    • Camera connected, if installed.
    • Power supply connected.
  2. Switch on the power supply. The unit starts automatically. There is no separate start button.
  3. Wait for startup. Give the system a short time to initialise.
  4. Watch the indicators. Depending on your hardware, one or more lights may turn on or blink while the system starts. This is normal.
  5. Wait for the network connection. The system will connect to its saved Wi-Fi network automatically.
What You May See

Immediately after power-up the dashboard may briefly show CONNECTING… or NO TELEMETRY. This is normal — wait a little longer before assuming something is wrong.

INNOVATEX IOT · User Manual Wi-Fi Setup
One-Time Setup

Connecting to Wi-Fi

◆

This setup is only needed once, or whenever the site's Wi-Fi details change. When the system has no saved network to use, it creates its own temporary Wi-Fi network so you can tell it which network to join.

  1. Power on the system. If no saved Wi-Fi is available, the unit automatically starts its setup mode.
  2. On your phone or laptop, open Wi-Fi settings. Look for the configuration network created by the device and connect to it.
  3. Open the setup page. It normally appears on screen automatically. If it does not, open a web browser and go to the address shown on the setup network's welcome page.
  4. Choose your site's Wi-Fi.
    • Select the Wi-Fi network the system should use.
    • Enter the Wi-Fi password.
    • Save the settings.
  5. Wait for the device to reconnect. The temporary setup network will disappear — this means the system has joined your network successfully.
  6. Check the dashboard. It should now show REALTIME and sensor readings should appear.
Tip

If you cannot see the setup network, wait one minute and look again. The device may still be starting up.

INNOVATEX IOT · User Manual Opening the Dashboard
Signing In

Opening the Dashboard

◆

The dashboard is a web page. You do not need to install anything — any modern browser on a phone, tablet or computer will work.

  1. Open a web browser.
  2. Go to the dashboard address provided by your installer.
  3. Enter your username.
  4. Enter your password.
  5. Select AUTHENTICATE.

Some browsers offer a Remember session option so you do not have to sign in each time.

Security

Do not use Remember session on a shared or public computer. Always sign out when you have finished.

If the Dashboard Does Not Open

  • Check that you typed the address correctly.
  • Check that your device has an internet connection.
  • Refresh the page and try again.
  • Try a different browser.
  • If it still does not open, contact your system administrator.

INNOVATEX IOT · User Manual The Dashboard
Screen Layout

Understanding the Dashboard

◆

After you sign in, the dashboard shows the current condition of your site. Each part of the screen covers one topic — the list below explains what you will find where.

What Each Section Shows

  • System status — the overall condition of the site in a single message, such as System Normal or an alert.
  • Connection status — whether the dashboard is receiving fresh information right now.
  • Sensor readings — temperature, humidity, ambient light, distance and motion.
  • Live camera — a live view from the camera, where one is installed.
  • Alarm control — switches the audible alarm on and off.
  • Lighting control — switches the perimeter lighting on and off.
  • Reports — lets you look back at recorded sensor history for a chosen period.
Good To Know

The dashboard shows information, but it does not replace your site's normal security and emergency procedures. Always follow those first.

INNOVATEX IOT · User Manual Sensor Readings
Reading the Values

Sensors & Readings

◆

Each sensor reports one physical measurement. The dashboard shows the value and, where relevant, a short plain-language interpretation.

Temperature

The current temperature measured at the site.

Humidity

The current moisture level in the air.

Ambient Light

How much light is present around the sensor. This value changes naturally between day and night.

Distance

How far away the nearest object is from the sensor.

CLEAR nothing is close — PROXIMITY something is nearby — OBSTRUCTION something is blocking the sensor.

Motion

Whether movement has been detected.

CLEAR no movement — MOTION movement detected — NO DATA no reading available.

Note

If a sensor shows NO DATA for more than a few minutes, see Common Troubleshooting near the back of this manual.

How Fresh Is the Data?

Connection Status

◆

The connection indicator tells you how recent the information on screen is. It is the quickest way to tell whether the system is healthy.

MessageWhat It MeansWhat To Do
CONNECTING… The system is still establishing communication. Wait a short time.
REALTIME New information is arriving normally. Nothing — this is correct.
STALE Information has not updated recently. Wait, then check Wi-Fi and internet.
NO DATA No usable sensor information is available. Check power, sensors and Wi-Fi.
OFFLINE The dashboard cannot reach the monitoring system. See Common Troubleshooting.
Normal Condition

REALTIME together with SYSTEM NORMAL means everything is working as it should.

INNOVATEX IOT · User Manual Controls
Remote Controls

Alarm & Lighting Controls

◆

The dashboard lets you switch two things at the site on and off: the audible alarm and the perimeter lighting.

Audible Alarm

  1. Open the dashboard and sign in.
  2. Find the Audible Alarm control.
  3. Switch it ON to sound the alarm.
  4. Switch it OFF to stop the alarm.

Perimeter Lighting

  1. Find the Perimeter Lighting control.
  2. Switch it ON to turn the lights on.
  3. Switch it OFF to turn the lights off.

If a command cannot be sent, the dashboard may show COMMAND FAILED. Check the connection and try again.

Important

Only authorised personnel should use these controls. Do not sound the alarm unnecessarily.

INNOVATEX IOT · User Manual Live Camera
Camera View

Using the Live Camera

◆

If your system includes a camera, the dashboard shows a live view from it. When the camera is working, a LIVE indicator is displayed.

Camera Controls

  • Pause — temporarily stops the picture on screen.
  • Resume — starts the picture again.
  • Mirror — flips the picture so it faces the other way.

The camera section may also show when the last image was received and whether the camera is currently streaming.

If the Camera Is Not Available

  1. Check that the camera unit has power.
  2. Check the Wi-Fi connection.
  3. Wait a minute for the camera to reconnect.
  4. Refresh the dashboard page.
  5. If it is still unavailable, contact your administrator.

INNOVATEX IOT · User Manual Reports
Looking Back

Reports

◆

The system keeps a record of what the sensors measured over time. A report lets you look back at a chosen period — useful for reviews, records, and investigating what happened at a particular moment.

To Create a Report

  1. Open the Security System Report section.
  2. Choose the From date and time.
  3. Choose the To date and time.
  4. Select Generate Report.
  5. Wait for the records to appear.

The most recent records are shown first. If nothing is found for the period you chose, the system will say: “No records found in the selected range.”

Printing or Saving a Report

  1. Select the print option.
  2. Choose a printer, or select Save as PDF.
  3. Save the report where you need it.

Reports Are Useful For

  • Security reviews
  • Site monitoring
  • Incident investigation
  • Maintenance records

New Network

Changing the Wi-Fi Network

◆

If your site moves to a new Wi-Fi network, or the network name or password changes, the system needs to be told the new details.

When This Is Needed

  • The Wi-Fi router has been replaced.
  • The Wi-Fi network name has changed.
  • The Wi-Fi password has changed.
  • The system can no longer connect to the network it used before.
  • The device has been reset by an authorised person.

What To Do

  1. Put the monitoring unit into Wi-Fi setup mode, following your installer's instructions.
  2. On your phone or laptop, connect to the setup network created by the device.
  3. Open the setup page in your browser.
  4. Select the new Wi-Fi network.
  5. Enter the new password.
  6. Save the settings.
  7. Wait for the system to reconnect.
  8. Open the dashboard and confirm it shows REALTIME.
Important

Give the system time to reconnect before trying again. Do not repeatedly reset the device.

INNOVATEX IOT · User Manual Safety
Important

Safety

◆

These rules protect both the equipment and the people working around it. Read them once and follow them at all times.

Electrical Safety

  • Do not touch electrical connections while the equipment is powered.
  • Check that the power supply matches the equipment before connecting it.
  • Keep cables tidy and out of the way of foot traffic.
  • Do not use damaged cables or plugs.

Equipment Safety

  • Do not expose the equipment to water.
  • Do not expose the equipment to excessive heat or direct sunlight.
  • Do not open or modify the hardware.
  • Avoid unnecessary power cycling — the system is designed to stay powered on.

Operating Safety

  • Only authorised personnel should operate the system.
  • Keep your username and password confidential.
  • Do not sound the alarm unnecessarily.
  • Treat FIRE ALERT as a real emergency until it is confirmed otherwise.
  • Treat INTRUDER ALERT as a real security event until it is confirmed otherwise.
  • Always follow your site's emergency and evacuation procedures.
Remember

The dashboard helps you monitor your site, but it does not replace emergency services or your normal security procedures.
